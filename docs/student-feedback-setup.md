# 익명 학생 의견함 설정

학생 화면은 익명 의견만 전송하고, 이름·학번·성적·목표 내신·관심 대학·백업 데이터는 전송하지 않습니다. 의견 목록 조회와 수정은 Apps Script가 발급한 관리자 세션 토큰이 있어야 가능합니다.

## 1. Google Sheet 준비

1. 의견 저장용 Google Sheet를 새로 만듭니다.
2. 주소의 `/d/`와 `/edit` 사이 값을 복사합니다. 이 값이 `FEEDBACK_SHEET_ID`입니다.
3. 시트 탭은 미리 만들지 않아도 됩니다. 스크립트가 기본 이름 `학생 의견`으로 만들고 헤더를 추가합니다.

저장 컬럼은 다음 순서입니다.

`id / 접수일시 / 의견 종류 / 의견 내용 / 학년 / 앱 버전 / 빌드일 / 현재 화면 / 화면 크기 / 브라우저 정보 / 처리상태 / 관리자 메모`

## 2. Apps Script 설치

1. Google Sheet에서 `확장 프로그램 → Apps Script`를 엽니다.
2. 기본 코드를 지우고 저장소의 `google-apps-script/feedback-api.gs` 전체를 붙여 넣습니다.
3. Apps Script의 `프로젝트 설정 → 스크립트 속성`에 아래 값을 추가합니다.

   - `FEEDBACK_SHEET_ID`: 1단계에서 복사한 Sheet ID
   - `FEEDBACK_ADMIN_PASSWORD`: 관리자 의견함에서 사용할 충분히 긴 비밀번호
   - `FEEDBACK_SHEET_NAME`: 선택 사항. 비우면 `학생 의견`

비밀번호는 학생 사이트 코드나 GitHub 저장소에 넣지 않습니다.

## 3. 웹 앱 배포

1. Apps Script 우측 상단 `배포 → 새 배포`를 누릅니다.
2. 유형은 `웹 앱`을 선택합니다.
3. 실행 사용자는 `나`로 설정합니다.
4. 액세스 권한은 익명 학생 제출을 위해 `모든 사용자`로 설정합니다.
5. 배포 후 끝이 `/exec`인 웹 앱 URL을 복사합니다.

웹 앱 자체는 공개 URL이지만 `createFeedback`만 익명으로 허용합니다. `listFeedback`과 `updateFeedback`은 관리자 비밀번호 로그인으로 받은 6시간짜리 세션 토큰 없이는 거부됩니다.

## 4. 사이트 연결

`src/feedback-config.mjs`의 한 곳에만 배포 URL을 입력합니다.

```js
export const FEEDBACK_GAS_URL = 'https://script.google.com/macros/s/배포_ID/exec';
```

변경 후 테스트하고 `main`에 commit/push하면 GitHub Pages에 반영됩니다.

## 5. 이후 스크립트 수정 시

Apps Script 코드를 수정하면 `배포 → 배포 관리 → 수정 → 새 버전`으로 재배포합니다. 같은 배포를 새 버전으로 갱신하면 `/exec` URL을 바꾸지 않아도 됩니다.

## 운영 확인 순서

1. 학생 화면에서 테스트 의견을 보냅니다.
2. 관리자 페이지의 `학생 의견` 탭을 열고 스크립트 속성의 관리자 비밀번호로 로그인합니다.
3. 테스트 의견이 `신규`로 보이는지 확인합니다.
4. 상태를 `확인중`으로 바꾸고 관리자 메모를 저장합니다.
5. 새로고침 후 상태와 메모가 유지되는지 확인합니다.

관리자 토큰은 브라우저 탭의 `sessionStorage`에만 보관됩니다. 탭 세션이 끝나거나 6시간이 지나면 다시 로그인해야 합니다.

학생 제출은 같은 브라우저 탭에서 성공 직후 30초 동안 다시 보낼 수 없습니다. 이 제한에는 제출 시각만 사용하며 학생 식별정보는 저장하지 않습니다.
