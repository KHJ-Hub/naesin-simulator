# 내신 시뮬레이터

배정고 수강설계 사이트와 분리해 운영하는 공개 정적 웹 도구입니다. 실제 성적은 서버로 전송하거나 브라우저에 자동 저장하지 않으며, 현재 화면에서만 유지됩니다.

## 사용

- 학교 과목 카탈로그 기반의 1학년 공통 과목 자동 생성 및 2·3학년 선택 과목 추가
- 2022 개정 교육과정 5등급제(1~5등급) 성적 입력
- 계산 버튼 기반의 학점 가중/단순 평균, 교과별 관리 방향 분석
- 목표 내신과 남은 평균·균형/초반 집중/후반 상승 시나리오 시뮬레이션
- 수동 백업 파일 저장·복구
- 학생 정보와 실제 성적을 포함한 교사용 결과표 인쇄 / PDF 저장

공개 주소는 GitHub Pages 설정 후 `https://khj-hub.github.io/naesin-simulator/`가 됩니다. 저장소의 `main`에 push하면 `.github/workflows/deploy-pages.yml`이 자동 배포합니다.

## 개발

```bash
npm test
```

학생 정보와 성적은 서버로 전송하지 않고 현재 탭의 실행 상태에만 보관하므로 새로고침하거나 탭을 닫기 전에 `내 데이터 백업`으로 파일을 저장해야 합니다. 학교 공통 설정과 관리자 과목 설정만 학생 개인 데이터와 분리해 브라우저 저장소를 사용할 수 있습니다. 결과표 인쇄 버튼을 누른 뒤 브라우저 인쇄 창에서 PDF로 저장할 수 있습니다.

학생 의견 기능은 이름·학번·성적을 수집하지 않고 익명 의견과 비식별 기술 정보만 별도 Google Sheet에 저장합니다. 배포 설정은 [익명 학생 의견함 설정](./docs/student-feedback-setup.md)을 참고하세요.

`src/course-catalog.mjs`는 현재 요청에서 명시된 과목을 기반으로 한 학교 카탈로그 계층입니다. 실제 운영 전에는 학교의 입학생 연도별 확정 과목·학점 목록으로 교체하거나, 이후 관리자 화면/일괄 등록 기능과 연결해야 합니다.
